Draw the panels on the satellite view. Made for a computer screen, not a phone.

## Drawing

- The map starts at the opportunity's map point. A new layout looks up Google's roof faces once; **Roof data** asks again (each lookup costs an API call).
- **Draw array (A):** drag a box and it fills with the build sheet's module at its catalog size, with the panel and row gaps. Started on a roof face, it lines up with that face and takes its pitch.
- Set the **pitch** before judging the fit: on a steep roof the panels look shorter from above.
- **Select (V):** move, turn, flip, duplicate or delete an array, and set its name, mount (roof, ground, tracker), module and shading. Names must be unique.
- **Add / remove panels (P)** and **Measure (M).** Measurements read along the slope, rounded down to the inch: yellow ones are stretched by the slope, blue ones are flat.
- Ctrl+Z and Ctrl+Y undo and redo. Right-drag pans with any tool. **Fit** zooms to the arrays. **Hide labels (L)** clears the array names off a busy roof; this browser remembers the choice.
- More under **Tips and shortcuts** in the side panel.

## Proposal view

Frames what the proposal's aerial picture shows. Move and zoom the map under the dashed frame, then **Save proposal view**. **Automatic view** goes back to framing on the arrays.

## What saving does

The layout becomes the master. The build sheet's arrays and module quantities are set from the drawing and it reprices. Each array's area and perimeter (for critter guard) show on the build sheet.
